智链参谋 · 前端代码包必读（10-30）
================================================

一、这个包是什么
------------------------------------------------
这是看板的最新代码，覆盖你项目里的同名文件就能用。
配套的数据包是另一个：智链参谋_数据导出_1026.zip（27 个文件，
那是给评审和看数据用的；跑程序用本包 output/ 里的原始表，
文件名和字段才是程序实际读的那套，两个包别搞混）。

本包内容：
  app/ui/dashboard.py        看板主程序（你改样式的地盘）
  app/ui/README.md           给你看的字段级契约，最全
  app/decision_support.py    三方案/留痕/偏差校准（纯计算，别改）
  app/daily_brief.py         今日简报模块
  app/agent.py               Agent 主程序
  app/dialect_*.py           方言理解三模块（Agent 依赖，别改）
  app/freshretail_agent/     生鲜 Agent 四工具
  config/freshretail_inventory.yaml   库存配置（别改）
  requirements.txt           依赖清单
  output/                    程序运行要读的 15 张表


二、怎么跑起来（三步）
------------------------------------------------
1) 解压本包到你项目根目录，选"覆盖同名文件"。
   如果你是空项目直接解压也行，结构就是能跑的完整结构。

2) 装依赖（第一次才需要）：
   python -m pip install -r requirements.txt
   注意 streamlit 必须是 1.66.1（点行选择是 1.35 之后的新特性，
   版本太老表格点不了行）。

3) 在项目根目录下运行：
   streamlit run app/ui/dashboard.py
   浏览器会自动打开，默认就是生鲜前置仓版。

四、你的地盘和不能碰的
------------------------------------------------
归你随便改：app/ui/ 目录（样式、布局、配色）。
新增的功能代码集中在 dashboard.py 里 5 个函数：
  render_trace_panel / _trace_chain / _trace_whatif /
  _trace_alpha / render_decision_log
改样式不用碰它们，别删就行。

不要动：app/ 下其他 py、config/、output/ 下的 csv。
这些是业务逻辑和数据，动了页面数字就不可信了。


五、三条硬约束（改视觉时贴在手边）
------------------------------------------------
1) 订货量的闸门是"目标水位"，不是 ROP。在库高于 ROP 但没到
   目标水位的仍要下单（04 表里 45 条"计划补货"就是这种）。
   按 ROP 当闸门会让这 45 条全变 0 件。
2) "当前配置"方案的订货量必须逐行等于 04 表 suggest_qty。
   代码里有自检，对不上会自动降级只显示推导。这段自检别删。
3) 0.7 倍不能写成"省货版"。实测它总成本比 1.0 倍高 34.5%
   （缺货罚 5 元/件 > 省下的报损 1 元/件），最低点其实是
   0.9 倍。三档统一用 1.0 是为了口径一致。


六、容易踩的四个点
------------------------------------------------
1) 商品没有名字（官方脱敏），列表写"SKU 145-802"这种格式。
2) 保质期筛选器只有"5 天"一个档，是照数据实况出的，不是漏做。
3) 07 表文件名叫"未来7天"，内容其实是 2024-06-26~07-02 的
   回测。对外统一说"7 天回测"，评委最爱追问这个。
4) 紧急度"正常"档是空的（0 条），真实结果，不是筛掉了。


七、改完自检五件事
------------------------------------------------
1) 补货表 200 行正常显示，点一行能展开三个分页；
2) 底部选 1.25 倍点"确认执行"，界面显示的合计要等于
   user_decisions.csv 里 applied_qty 求和；
3) 顶部今日简报正常显示，数字和"今日概览"卡片对得上；
4) 方言下拉选"桂柳话"随口说句方言，回复是方言原句+普通话两行；
5) 切到"制造企业（保底）"再切回生鲜，都不报错。
